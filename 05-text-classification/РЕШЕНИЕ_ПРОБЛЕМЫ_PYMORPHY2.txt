⚠️ ПРОБЛЕМА:
   pymorphy2 не совместим с Python 3.13 (использует устаревшие API)

✅ РЕШЕНИЕ 1: Скрипт работает БЕЗ лемматизации
   
   Скрипт автоматически обрабатывает эту ситуацию и продолжает работу.
   Лемматизация - это дополнительная функция, но не обязательная.
   
   БЕЗ лемматизации скрипт все равно:
   ✅ Токенизирует текст
   ✅ Удаляет стоп-слова
   ✅ Удаляет спецсимволы
   ✅ Преобразует в числовую форму
   ✅ Обучает модели
   ✅ Классифицирует текст
   
   Качество может быть немного ниже, но для учебных целей достаточно!

═══════════════════════════════════════════════════════════════
  РЕШЕНИЕ 2: Использовать Python 3.11 или 3.12
═══════════════════════════════════════════════════════════════

Если нужна полная лемматизация, используйте Python 3.11 или 3.12:

1. Установите Python 3.11 или 3.12
2. Создайте виртуальное окружение:
   python3.11 -m venv venv
   # или
   python3.12 -m venv venv

3. Активируйте окружение:
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate

4. Установите зависимости:
   pip install -r requirements_text_classification.txt

═══════════════════════════════════════════════════════════════
  РЕШЕНИЕ 3: Использовать альтернативу (опционально)
═══════════════════════════════════════════════════════════════

Можно использовать другие библиотеки для морфологического анализа:
- natasha (современная альтернатива)
- razdel (токенизация)

Но для учебных целей это не обязательно!
