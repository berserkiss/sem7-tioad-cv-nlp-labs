# Классификация текста: Предобработка и обучение моделей

Этот проект реализует полный пайплайн для классификации текста на русском языке, включая предобработку, векторизацию, обучение моделей и классификацию новых данных.

## Описание

Скрипт выполняет следующие задачи:
1. ✅ Загрузка/скачивание датасета для классификации текста
2. ✅ Предобработка текста (токенизация, лемматизация, удаление стоп-слов)
3. ✅ Преобразование в числовую форму (Bag of Words, TF-IDF)
4. ✅ Обучение нескольких моделей классификаторов (Naive Bayes, SVM, Random Forest)
5. ✅ Выбор лучшей модели на основе метрик
6. ✅ Парсинг новых данных с сайтов
7. ✅ Классификация новых данных

## Установка зависимостей

```bash
pip install -r requirements_text_classification.txt
```


## Где взять датасет?

### Вариант 1: Использовать встроенный датасет (по умолчанию)
Скрипт автоматически создает синтетический датасет отзывов на товары для демонстрации.

### Вариант 2: Скачать датасет с Kaggle

**Рекомендуемые датасеты для русскоязычной классификации:**

1. **Russian Sentiment Analysis Dataset**
   - URL: https://www.kaggle.com/datasets/cryptexcode/russian-sentiment-analysis-dataset
   - Описание: Датасет отзывов с метками тональности (положительный/отрицательный)

2. **Russian Reviews Dataset**
   - URL: https://www.kaggle.com/datasets/artemkonevskoy/russian-reviews-dataset
   - Описание: Большой датасет русскоязычных отзывов

3. **Lenta.ru News Dataset**
   - URL: https://www.kaggle.com/datasets/yutkin/corpus-of-russian-news-articles-from-lenta
   - Описание: Датасет новостей с категориями (для классификации тем)

**Как скачать с Kaggle:**
1. Зарегистрируйтесь на Kaggle (https://www.kaggle.com)
2. Скачайте API credentials (Settings → API → Create New Token)
3. Установите kaggle: `pip install kaggle`
4. Поместите `kaggle.json` в `~/.kaggle/` (или `C:\Users\YourUsername\.kaggle\` на Windows)
5. Скачайте датасет:
   ```bash
   kaggle datasets download -d dataset-name
   unzip dataset-name.zip
   ```

### Вариант 3: Использовать свой CSV файл

Создайте CSV файл с колонками:

Затем модифицируйте код в `DatasetLoader.load_from_file()` для загрузки вашего файла.

## Методы предобработки

1. **Токенизация** - разбиение текста на слова
2. **Лемматизация** - приведение слов к нормальной форме (использует pymorphy2)
3. **Удаление стоп-слов** - удаление служебных слов
4. **Удаление спецсимволов** - очистка от знаков препинания
5. **Приведение к нижнему регистру**

## Методы векторизации

1. **Bag of Words (BoW)** - подсчет частоты слов
2. **TF-IDF** - Term Frequency-Inverse Document Frequency

## Модели классификаторов

1. **Naive Bayes** - вероятностный классификатор
2. **SVM (Support Vector Machine)** - метод опорных векторов
3. **Random Forest** - ансамбль решающих деревьев

## Метрики оценки

Для выбора лучшей модели используются:
- **Accuracy** - точность
- **Precision** - точность (precision)
- **Recall** - полнота
- **F1-score** - гармоническое среднее precision и recall
