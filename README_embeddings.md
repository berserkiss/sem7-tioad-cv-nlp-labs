# Сравнение качества эмбеддингов

Этот скрипт реализует сравнение различных моделей эмбеддингов (Word2Vec и FastText) на задачах поиска семантически схожих слов и выполнения аналогий.

## Установка зависимостей

```bash
pip install -r requirements_embeddings.txt
```

Или вручную:
```bash
pip install gensim matplotlib scikit-learn numpy
```

## Использование

```bash
python embeddings_comparison.py
```

## Что делает скрипт

1. **Загружает предобученные модели:**
   - Word2Vec (Google News) - ~3 млн слов
   - FastText (Wiki News) - ~1 млн слов

2. **Ищет семантически схожие слова:**
   - Для заданного слова находит топ-10 наиболее похожих слов
   - Сравнивает результаты между моделями

3. **Выполняет аналогии:**
   - Примеры: "Париж - Франция = Минск - ?" → "Беларусь"
   - "Италия - пицца = Япония - ?" → "суши"
   - Тестирует несколько аналогий и подсчитывает точность

4. **Визуализирует векторы:**
   - Использует t-SNE для снижения размерности до 2D
   - Использует PCA для альтернативной визуализации
   - Создает графики с 20-30 словами из разных категорий

5. **Сравнивает модели:**
   - Выводит статистику по точности аналогий
   - Делает выводы о преимуществах каждой модели

## Результаты

После выполнения скрипта будут созданы:
- `embeddings_tsne.png` - визуализация с помощью t-SNE
- `embeddings_pca.png` - визуализация с помощью PCA

## Примечания

- При первом запуске модели будут автоматически скачаны (может занять несколько минут)
- Модели загружаются в кэш gensim (обычно в `~/.gensim/`)
- Используются английские модели, так как они наиболее доступны и хорошо протестированы

## Примеры аналогий в скрипте

1. `king - man = queen - ?` → `woman`
2. `paris - france = minsk - ?` → `belarus`
3. `italy - pizza = japan - ?` → `sushi`
4. `good - better = bad - ?` → `worse`
5. `computer - keyboard = car - ?` → `steering_wheel`

## Структура кода

- `EmbeddingModel` - класс для работы с одной моделью
- `EmbeddingComparator` - класс для сравнения моделей
- `main()` - основная функция с тестами и визуализацией

## Выводы

Скрипт автоматически выводит сравнение моделей:
- **Word2Vec**: лучше для частых слов, быстрее, но не работает с редкими словами
- **FastText**: работает с редкими словами и OOV (out-of-vocabulary), лучше для морфологически богатых языков
