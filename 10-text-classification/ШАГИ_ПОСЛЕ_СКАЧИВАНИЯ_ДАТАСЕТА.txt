═══════════════════════════════════════════════════════════════
  ВАЖНО: РАЗМЕР ДАТАСЕТА
═══════════════════════════════════════════════════════════════

Ваш датасет может быть очень большим (более 500 тысяч строк).

По умолчанию скрипт использует выборку из 10,000 записей для обучения.
Это достаточно для демонстрации и быстрого обучения.

Если хотите использовать БОЛЬШЕ данных:
   Откройте text_classification.py
   Найдите строку: max_samples=10000
   Измените на нужное число (например, 50000) или None для всего датасета

Если хотите использовать МЕНЬШЕ данных (для быстрого теста):
   Измените max_samples=1000 или max_samples=5000

═══════════════════════════════════════════════════════════════
  СТРУКТУРА ВАШЕГО ДАТАСЕТА
═══════════════════════════════════════════════════════════════

Ваш датасет содержит:
   - text: тексты отзывов
   - label: метки (0 = отрицательный, 1 = положительный)
   - src: источник данных

Скрипт автоматически распознает колонки 'text' и 'label'.

═══════════════════════════════════════════════════════════════
  ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
═══════════════════════════════════════════════════════════════

❌ Ошибка: ModuleNotFoundError: No module named 'pandas'
   → Решение: pip install pandas scikit-learn nltk

❌ Ошибка: ModuleNotFoundError: No module named 'pymorphy2'
   → Решение: pip install pymorphy2 pymorphy2-dicts-ru

❌ Скрипт работает очень долго
   → Решение: Уменьшите max_samples в коде (например, до 5000)

❌ Ошибка при загрузке датасета
   → Решение: Убедитесь, что файл находится в папке datasets/
              и называется sentiment_dataset.csv
