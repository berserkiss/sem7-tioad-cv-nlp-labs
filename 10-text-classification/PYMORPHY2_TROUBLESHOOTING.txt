  FIXING THE PYMORPHY2 ISSUE
═══════════════════════════════════════════════════════════════

⚠️ THE PROBLEM:
   pymorphy2 isn't compatible with Python 3.13 (it uses deprecated APIs)

✅ FIX 1: The script runs WITHOUT lemmatization

   The script detects this and keeps going.
   Lemmatization is a nice-to-have, not a requirement.

   WITHOUT lemmatization the script still:
   ✅ Tokenizes the text
   ✅ Removes stop words
   ✅ Removes special characters
   ✅ Vectorizes it
   ✅ Trains the models
   ✅ Classifies text

   Quality may be slightly lower, but it's fine for coursework!

═══════════════════════════════════════════════════════════════
  FIX 2: Use Python 3.11 or 3.12
═══════════════════════════════════════════════════════════════

If you need full lemmatization, use Python 3.11 or 3.12:

1. Install Python 3.11 or 3.12
2. Create a virtual environment:
   python3.11 -m venv venv
   # or
   python3.12 -m venv venv

3. Activate it:
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate

4. Install dependencies:
   pip install -r requirements_text_classification.txt
