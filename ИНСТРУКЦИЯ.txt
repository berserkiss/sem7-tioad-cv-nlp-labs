═══════════════════════════════════════════════════════════════
  ГДЕ ВЗЯТЬ ДАТАСЕТ?
═══════════════════════════════════════════════════════════════

📌 ВАРИАНТ 1: Использовать встроенный датасет (по умолчанию)
   Скрипт автоматически создаст синтетический датасет для демонстрации.
   Просто запустите: python text_classification.py

📌 ВАРИАНТ 2: Скачать с Kaggle (РЕКОМЕНДУЕТСЯ)
   
   Шаг 1: Зарегистрируйтесь на Kaggle
   → https://www.kaggle.com
   
   Шаг 2: Скачайте API credentials
   → Settings → API → Create New Token
   → Сохраните файл kaggle.json
   
   Шаг 3: Поместите kaggle.json в нужную папку:
   Windows: C:\Users\ВашеИмя\.kaggle\kaggle.json
   Linux/Mac: ~/.kaggle/kaggle.json
   
   Шаг 4: Установите библиотеку kaggle:
   → pip install kaggle
   
   Шаг 5: Скачайте датасет:
   → python download_dataset.py
   
   Или вручную:
   → kaggle datasets download -d cryptexcode/russian-sentiment-analysis-dataset
   → unzip russian-sentiment-analysis-dataset.zip
   → Переместите CSV в папку datasets/

📌 ВАРИАНТ 3: Использовать свой CSV файл
   
   Создайте CSV файл с колонками:
   - text: текстовые данные
   - label: метка класса (0 или 1)
   
   Поместите файл в папку datasets/
   Скрипт автоматически найдет и загрузит его!

📌 РЕКОМЕНДУЕМЫЕ ДАТАСЕТЫ С KAGGLE:
   
   1. Russian Sentiment Analysis Dataset
      → cryptexcode/russian-sentiment-analysis-dataset
      → Отзывы с метками тональности
   
   2. Russian Reviews Dataset
      → artemkonevskoy/russian-reviews-dataset
      → Большой датасет отзывов
   
   3. Lenta.ru News Corpus
      → yutkin/corpus-of-russian-news-articles-from-lenta
      → Новости с категориями

═══════════════════════════════════════════════════════════════
  БЫСТРЫЙ СТАРТ
═══════════════════════════════════════════════════════════════

1. Установите зависимости:
   pip install -r requirements_text_classification.txt

2. Запустите скрипт:
   python text_classification.py

3. Скрипт автоматически:
   - Загрузит/создаст датасет
   - Проведет предобработку
   - Обучит модели
   - Выберет лучшую
   - Парсит и классифицирует новые данные

  ВАЖНЫЕ ЗАМЕЧАНИЯ

⚠ Для работы с русским языком требуется:
   - pymorphy2 (для лемматизации)
   - pymorphy2-dicts-ru (словари для русского языка)

⚠ Если датасет не найден, скрипт использует синтетический
   датасет для демонстрации функциональности.

⚠ Для лучших результатов используйте датасеты с минимум
   1000+ примерами.

⚠ Парсинг веб-сайтов требует соблюдения правил использования
   (robots.txt, rate limiting).
