# 🌐 КАК ВКЛЮЧИТЬ РЕАЛЬНЫЙ ПАРСИНГ С САЙТОВ

## ❓ Почему используются примеры из массива?

**Причина:** В коде не указаны реальные URL для парсинга, поэтому скрипт автоматически использует примеры отзывов.

### Текущая ситуация в коде:

```python
review_urls = [
    # 'https://otzovik.com/reviews/...',  # ЗАКОММЕНТИРОВАНО!
    # 'https://irecommend.ru/content/...',  # ЗАКОММЕНТИРОВАНО!
]
```

**Результат:** Так как массив пустой или все URL закомментированы, скрипт переходит к использованию примеров.

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### 1. Структура сайтов может меняться

- Сайты могут изменить HTML-структуру
- Парсер может потребовать обновления
- Некоторые сайты могут блокировать парсинг

### 2. Соблюдайте правила

- ✅ Проверьте `robots.txt` сайта
- ✅ Не делайте слишком частые запросы
- ✅ Используйте для учебных целей
- ✅ Соблюдайте условия использования

### 3. Если парсинг не работает

Скрипт автоматически переключится на примеры отзывов, если:
- URL недоступен
- Сайт блокирует запросы
- Структура сайта изменилась
- Ошибка сети
