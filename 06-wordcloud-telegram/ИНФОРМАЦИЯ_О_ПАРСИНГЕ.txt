✅ РЕАЛИЗОВАНО: Парсинг отзывов с сайтов

Скрипт поддерживает парсинг отзывов с следующих сайтов:

1. ОТЗОВИК (otzovik.com)
   - Сайт с отзывами о товарах и услугах
   - URL пример: https://otzovik.com/reviews/...
   - Тип парсинга: 'otzovik'

2. IRECOMMEND (irecommend.ru)
   - Сайт с отзывами о товарах
   - URL пример: https://irecommend.ru/content/...
   - Тип парсинга: 'irecommend'

3. ЯНДЕКС.МАРКЕТ (market.yandex.ru)
   - Отзывы о товарах на Яндекс.Маркете
   - URL пример: https://market.yandex.ru/product/.../reviews
   - Тип парсинга: 'yandex_market'

4. УНИВЕРСАЛЬНЫЙ ПАРСЕР
   - Работает с любыми сайтами, содержащими отзывы
   - Автоматически извлекает тексты из параграфов и блоков
   - Тип парсинга: 'generic' (по умолчанию)

═══════════════════════════════════════════════════════════════
  ВАЖНЫЕ ЗАМЕЧАНИЯ
═══════════════════════════════════════════════════════════════

⚠️ СОБЛЮДЕНИЕ ПРАВИЛ:
   - Проверьте robots.txt сайта перед парсингом
   - Не делайте слишком частые запросы (добавьте задержки)
   - Соблюдайте условия использования сайта
   - Используйте парсинг только для учебных целей

⚠️ ЗАЩИТА ОТ ПАРСИНГА:
   - Некоторые сайты могут блокировать парсинг
   - Может потребоваться использование прокси или других методов
   - Для продакшена лучше использовать официальные API

⚠️ СТРУКТУРА САЙТОВ:
   - Структура сайтов может меняться
   - Парсер может потребовать адаптации под конкретный сайт
   - Универсальный парсер работает с большинством сайтов

reviews = scraper.scrape_from_url(
    'https://otzovik.com/reviews/12345',
    site_type='otzovik'
)

urls = [
    'https://otzovik.com/reviews/...',
    'https://irecommend.ru/content/...'
]
reviews = scraper.scrape_reviews_from_urls(urls, max_reviews=20)
