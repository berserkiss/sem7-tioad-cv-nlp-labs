# ☁️ ОБЛАКО СЛОВ ИЗ БЕСЕДЫ В TELEGRAM

## 📋 Описание

Этот скрипт создает красивое облако слов из экспортированной беседы в Telegram. Вы можете выбрать сообщения конкретного человека (мамы, друга, любимого человека) и создать уникальное облако слов, которое отражает наиболее частые слова этого человека.

**Применение:**
- Создание индивидуальной открытки
- Анализ стиля общения
- Подарок на день рождения или праздник
- Визуализация общения с близкими

---

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements_wordcloud.txt
```

Или вручную:
```bash
pip install wordcloud matplotlib pandas nltk pillow beautifulsoup4
```

### 2. Экспорт беседы из Telegram

#### Способ 1: Через приложение Telegram Desktop

1. Откройте Telegram Desktop
2. Выберите нужную беседу
3. Нажмите на три точки (меню) → **Export chat history**
4. Выберите формат: **JSON** (рекомендуется) или HTML
5. Сохраните файл в папку со скриптом

#### Способ 2: Использовать пример

Скрипт автоматически создаст пример беседы, если файл экспорта не найден.

### 3. Запуск скрипта

```bash
python wordcloud_telegram.py
```

## 📁 Форматы экспорта

Скрипт поддерживает несколько форматов:

### JSON (рекомендуется)
- Формат: `result.json` или `telegram_export.json`

- Формат: `.txt`

## 🎨 Настройка облака слов

### Базовые параметры

В функции `main()` можно изменить:

```python
generator = WordCloudGenerator(
    width=1200,           # Ширина изображения
    height=600,           # Высота изображения
    background_color='white'  # Цвет фона
)

generator.generate(
    processed_text,
    output_path='wordcloud.png',
    max_words=100,        # Максимальное количество слов
    colormap='viridis'    # Цветовая схема
)
```

### Доступные цветовые схемы:

- `'viridis'` - сине-зеленая (по умолчанию)
- `'plasma'` - фиолетово-розовая
- `'inferno'` - огненная
- `'magma'` - магматическая
- `'coolwarm'` - сине-красная
- `'autumn'` - осенняя
- `'winter'` - зимняя
- `'spring'` - весенняя
- `'summer'` - летняя

## 🎭 Создание облака в виде контура

### Шаг 1: Подготовка маски

Создайте черно-белое изображение:
- **Белый** - где должны быть слова
- **Черный** - где слов не должно быть

**Примеры контуров:**
- Сердце ❤️
- Звезда ⭐
- Круг ⭕
- Любая фигура

### Шаг 2: Использование маски

```python
generator.generate(
    processed_text,
    output_path='wordcloud_heart.png',
    mask_path='heart_mask.png',  # Путь к маске
    max_words=100,
    colormap='plasma'
)
```

### Где взять маски:

1. **Создать самостоятельно:**
   - Нарисовать в Paint/GIMP/Photoshop
   - Черно-белое изображение
   - Сохранить как PNG

2. **Скачать готовые:**
   - Поиск "word cloud mask" в интернете
   - Использовать силуэты

3. **Использовать эмодзи:**
   - Конвертировать эмодзи в изображение
   - Использовать как маску

```python
    width=2000,   # Больше = выше качество
    height=1000
)
```

```python
generator.generate(..., max_words=200)  # Больше слов
```

### Изменение относительного масштабирования

В коде можно изменить `relative_scaling`:
- `0.5` - более равномерное распределение
- `1.0` - больше контраста по размерам

## ⚠️ Важные замечания

### Удаление стоп-слов

✅ **Уже реализовано!** Скрипт автоматически:
- Удаляет стоп-слова (и, в, на, с, и т.д.)
- Удаляет короткие слова (менее 3 символов)
- Оставляет только значимые слова

### Качество результата

Для хорошего результата нужно:
- **Минимум 50-100 сообщений** от выбранного человека
- **Разнообразный текст** (не только односложные ответы)
- **Правильный экспорт** из Telegram

### Проблемы с русским языком

Если слова отображаются неправильно:
1. Установите шрифт для русского языка
2. Укажите путь к шрифту в коде:
   ```python
   font_path='path/to/russian_font.ttf'
   ```
