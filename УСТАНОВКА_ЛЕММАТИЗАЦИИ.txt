✅ РЕКОМЕНДУЕТСЯ: pymystem3 (MyStem от Яндекса)

MyStem - морфологический анализатор от Яндекса, обертка pymystem3
совместима с Python 3.13 и проста в использовании.

Установка:
   pip install pymystem3

Преимущества:
   ✅ Работает с Python 3.13
   ✅ Простой API
   ✅ Быстрая работа
   ✅ Хорошая точность лемматизации
   ✅ Разработано Яндексом

АЛЬТЕРНАТИВА: Natasha

Natasha - современная библиотека для обработки русского языка,
совместима с Python 3.13.

Установка:
   pip install natasha

Преимущества:
   ✅ Работает с Python 3.13
   ✅ Современная и активно поддерживается
   ✅ Хорошая точность лемматизации
   ✅ Включает другие инструменты NLP
   ⚠️ Требует больше ресурсов

═══════════════════════════════════════════════════════════════
  ДРУГИЕ АЛЬТЕРНАТИВЫ
═══════════════════════════════════════════════════════════════

1. MyStem (Яндекс)
   - Консольное приложение
   - Требует установки отдельного ПО
   - Быстрая работа
   - Установка: скачать с сайта Яндекса

2. DeepPavlov
   - Платформа для NLP
   - Предобученные модели
   - Требует больше ресурсов
   - Установка: pip install deeppavlov

3. spaCy (с русской моделью)
   - Популярная библиотека NLP
   - Требует загрузки русской модели
   - Установка: 
     pip install spacy
     python -m spacy download ru_core_news_sm

═══════════════════════════════════════════════════════════════
  КАК ИСПОЛЬЗОВАТЬ
═══════════════════════════════════════════════════════════════

Скрипт автоматически попытается использовать:
1. pymorphy2 (если работает)
2. natasha (если установлена и pymorphy2 не работает)
3. Без лемматизации (если ничего не работает)

Просто установите natasha:
   pip install natasha

И запустите скрипт - он автоматически использует natasha!

═══════════════════════════════════════════════════════════════
  ПРОВЕРКА РАБОТЫ
═══════════════════════════════════════════════════════════════

После установки natasha, при запуске скрипта вы увидите:
   "Используется Natasha для лемматизации (совместима с Python 3.13)"

Вместо предупреждения о том, что лемматизация не работает.
