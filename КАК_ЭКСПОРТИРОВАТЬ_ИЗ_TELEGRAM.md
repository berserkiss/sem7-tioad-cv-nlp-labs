# 📤 КАК ЭКСПОРТИРОВАТЬ БЕСЕДУ ИЗ TELEGRAM

## 🚀 ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1: Установите Telegram Desktop

Если у вас еще нет Telegram Desktop:
1. Скачайте с официального сайта: https://desktop.telegram.org/
2. Установите и войдите в свой аккаунт

### Шаг 2: Откройте нужную беседу

1. Запустите Telegram Desktop
2. Найдите нужную беседу (с мамой, другом, любимым человеком)
3. Откройте её

### Шаг 3: Экспортируйте историю беседы

1. **Нажмите на три точки** (меню) в правом верхнем углу беседы
2. Выберите **"Export chat history"** (Экспорт истории чата)
3. В появившемся окне:
   - ✅ Выберите формат: **JSON** (рекомендуется) или HTML
   - ✅ Выберите период: **Entire history** (Вся история) или нужный период
   - ✅ Выберите тип: **Personal chats** (Личные чаты)
   - ✅ Нажмите **Export** (Экспорт)

### Шаг 4: Сохраните файл

1. Выберите папку для сохранения
2. **ВАЖНО:** Сохраните файл в папку со скриптом `wordcloud_telegram.py`
3. Файл будет называться `result.json` (или другое имя, если указали)

### Шаг 5: Запустите скрипт

```bash
python wordcloud_telegram.py
```

Скрипт автоматически найдет файл `result.json` и обработает его!

---

## 📁 ГДЕ НАЙТИ ФАЙЛ ЭКСПОРТА?

После экспорта файл обычно сохраняется в:
- **Windows:** `C:\Users\ВашеИмя\Downloads\` или указанная вами папка
- **Mac:** `~/Downloads/` или указанная вами папка
- **Linux:** `~/Downloads/` или указанная вами папка

**Имя файла:**
- `result.json` (стандартное имя)
- Или имя, которое вы указали при экспорте

## 📋 ФОРМАТЫ ЭКСПОРТА

### JSON (рекомендуется) ✅

**Преимущества:**
- Структурированный формат
- Легко парсится
- Содержит всю информацию

**Структура:**
```json
{
  "name": "Имя беседы",
  "type": "personal_chat",
  "messages": [
    {
      "date": "2024-01-15T10:00:00",
      "from": "Имя отправителя",
      "text": "Текст сообщения"
    }
  ]
}
```

### HTML

**Преимущества:**
- Можно открыть в браузере
- Визуально читаемый

**Недостатки:**
- Сложнее парсить
- Может потребоваться адаптация парсера

## 🎯 ВЫБОР КОНКРЕТНОГО ЧЕЛОВЕКА

### Автоматический выбор

Скрипт автоматически:
1. Находит всех отправителей в беседе
2. Выбирает первого (можно изменить)

### Ручной выбор

Откройте `wordcloud_telegram.py` и найдите строки (около 520):

```python
# Для демонстрации выбираем первого (можно сделать интерактивный выбор)
selected_sender = list(senders)[0]
```

Измените на нужное имя:
```python
# Выберите конкретного человека
selected_sender = "Мама"  # Или "Друг", "Любимый человек" и т.д.
```

Или сделайте интерактивный выбор:
```python
print("Доступные отправители:")
for i, sender in enumerate(senders, 1):
    print(f"  {i}. {sender}")

choice = input("\nВведите номер отправителя: ")
selected_sender = list(senders)[int(choice) - 1]
```

## ✅ ПРОВЕРКА ЭКСПОРТА

### Как проверить, что экспорт правильный:

1. **Откройте файл `result.json`** в текстовом редакторе
2. **Проверьте структуру:**
   - Должен быть ключ `"messages"`
   - В сообщениях должны быть поля `"from"` и `"text"`
   - Текст должен быть на русском языке

### Пример правильного экспорта:

```json
{
  "name": "Беседа с Мамой",
  "messages": [
    {
      "date": "2024-01-15T10:00:00",
      "from": "Мама",
      "text": "Привет, как дела?"
    },
    {
      "date": "2024-01-15T10:05:00",
      "from": "Я",
      "text": "Все хорошо!"
    }
  ]
}
```

## 🔍 РЕШЕНИЕ ПРОБЛЕМ

### Проблема 1: Файл не найден

**Решение:**
- Убедитесь, что файл находится в папке со скриптом
- Проверьте имя файла (должно быть `result.json` или другое из списка)
- Или укажите полный путь в коде

### Проблема 2: Сообщения не парсятся

**Решение:**
- Проверьте формат файла (должен быть JSON)
- Убедитесь, что в файле есть поле `"messages"`
- Проверьте структуру сообщений

### Проблема 3: Неправильные имена отправителей

**Решение:**
- В Telegram имена могут быть разными
- Проверьте, как именно записано имя в экспорте
- Используйте точное имя из файла

### Проблема 4: Мало сообщений

**Решение:**
- Для хорошего облака слов нужно минимум 50-100 сообщений
- Экспортируйте всю историю беседы
- Выберите беседу с большим количеством сообщений
